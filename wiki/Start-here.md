# Start here

This page is for a scorekeeper. It tells you what to do the first time that you open QBSheet.

## Before you start

You need one of these two things:

- A game file from the tournament staff. The file name ends in `.qbj` or `.qbg`.
- The address of the tournament control server, and a pairing code for your room.

You do not need an account. You do not need a password.

## Step 1. Open QBSheet

1. Open the QBSheet address in Google Chrome. Another modern browser also works.
2. Wait for the start screen. The screen shows the title and the words
   *A focused, offline-ready scoresheet for quiz bowl*.

If the screen shows a red warning about storage, read
[Troubleshooting](Troubleshooting#the-browser-will-not-save-anything).

## Step 2. Practice first

Practice mode teaches you the scoresheet with a guided game. It uses the real scoresheet and
example teams. It changes no tournament data.

1. Find the section **New to QBSheet?**.
2. Select **Practice scoring**.
3. Follow each step in the guide.

The guide covers these tasks:

- Set the starting lineups.
- Score a power, a ten, and a bonus.
- Score a neg and a rebound.
- Correct an earlier question.
- Undo a mistake.
- Substitute a player.

QBSheet saves your practice game and your position in the guide on this device. To continue later,
select **Resume practice**.

## Step 3. Check the device

Do this on every device that you plan to use in a room. Do it before the tournament day.

1. Select **Check this device** at the top of the start screen.
2. Read each result.
3. Correct every failure in the section **Required for a safe game**.

[Prepare a device](Prepare-a-device) explains each check.

## Step 4. Score the real game

Now choose your workflow:

- The staff gave you a file. Read [Score a game from a file](Score-a-game-from-a-file).
- The staff gave you a server address and a pairing code. Read
  [Score a connected game](Score-a-connected-game).

## Two rules for the room

1. **Use one tab.** Score one game in one browser tab. If you open a second tab, QBSheet shows a
   notice and only one tab keeps control of the game.
2. **Download a backup.** Download a QBJ file when the game ends. Do this also if a server
   accepted the result. A message from a server is not a backup.
