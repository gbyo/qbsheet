# Finish a game

This page tells you how to close a game and how to hand over the result.

## Step 1. End regulation play

1. Open the Game / More menu.
2. Select **End regulation**.

If the format needs overtime, QBSheet starts overtime with the rules from the format.

## Step 2. Read the review

QBSheet shows a review before it sends anything.

1. Read every warning. A warning names an unfinished question or a tie.
2. Fix every blocker. QBSheet does not send a result while a blocker is open.
3. Confirm the review.

## Step 3. Hand over the result

The screen now depends on your workflow.

### A connected game

1. Read the line **Result sent**. This line means that the server accepted the result.
2. Select the download action and keep the QBJ file. This file is your backup.
3. Confirm the handoff if the room asks for a confirmation.

A connected game is complete after the explicit handoff acknowledgement.

### A file-only game

1. Select the download action.
2. Upload the file with the instruction for your room.
3. Confirm that you uploaded the file.

A file-only game is complete after QBSheet writes the QBJ file without an error.

## Always keep a file

Download the QBJ file even when the server accepted the result. A message from a server is not a
backup. The download costs a few seconds. A lost game costs a round.

## What happens to the record

- QBSheet keeps a completed record on the device for seven days.
- QBSheet does not delete a record because a server accepted the result.
- QBSheet does not delete a record because you downloaded a QBJ file.
- The start screen lists recent games. You can open a record again from that list.

## The two file shapes on the completion screen

| File | Use |
| --- | --- |
| An official QBJ document | The default. Use this file. |
| A legacy match-only QBJ document | Use this file only when another tool needs it. |

The second file sits under a **More…** menu. It is there for compatibility, not for daily use.

## A result keeps the identity of the assignment

A result carries the same identifiers as the assignment. The tournament, the phase, the round, the
match, the teams, and the players keep their identifiers.

Because of this, tournament control software finds the game with a direct lookup. It does not guess
from a file name.
