# Score a game from a file

Use this workflow when the tournament staff give you a file. This workflow needs no network
connection and no server.

## What you can open

| File | Support |
| --- | --- |
| An official QBJ document for one game | Full support. This is the preferred file. |
| An official QBJ document for a complete tournament | Full support. QBSheet shows a game list. |
| A match-only QBJ document | Support for compatibility. Other tools write this shape. |
| A legacy `.qbg` game package | Import only. Do not make new `.qbg` files. |

[Files and formats](Files-and-formats) explains each shape.

## Step 1. Open the file

1. Find the section **Start scoring** on the start screen.
2. Find the option **Open a game file**.
3. Select the file button, then choose your file.

QBSheet reads the file on your device. The file does not go to a server.

## Step 2. Choose the game, if QBSheet asks

QBSheet asks only when the file holds more than one game that you can score.

1. Read the game list. QBSheet groups the list by round.
2. Select the row for your room.

QBSheet lists unplayed games first. QBSheet marks a game that already holds a score. QBSheet never
opens such a game without your instruction.

## Step 3. Give the information that the file leaves out, if QBSheet asks

A generic QBJ file can leave out information that QBSheet needs. QBSheet asks you. QBSheet does not
guess.

| QBSheet asks for | Reason |
| --- | --- |
| The scoring rules | The file does not say enough about the format. QBSheet never assumes a named rule set. |
| The players | The file names the teams but not the players. Type the names. |

QBSheet also tells you when the file gives no room procedure. In that case QBSheet does not enforce
a substitution rule, a timeout rule, or a clock rule that it does not know.

## Step 4. Set the starting lineups

1. Read the roster for each team.
2. Select the players who start the game.
3. Confirm each lineup.

## Step 5. Score the game

Read [During the game](During-the-game) for the controls, the corrections, and the protests.

## Step 6. Hand over the result

1. End the game. Read [Finish a game](Finish-a-game).
2. Select **Download QBJ backup**.
3. Give the file to the staff. Follow the instruction for your room.

The file name looks like this:

    R04_Room-204_Ninety-Six_vs_Greenwood.result.qbj

The name is a label for a person. No software reads the name to decide what the file is. The
identifiers inside the file carry the identity.

## A file-only game is complete after a good download

QBSheet marks a file-only game complete when it writes the QBJ file without an error. QBSheet keeps
the record on the device for seven days. QBSheet does not delete the record because you downloaded
the file.
